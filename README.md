# Peak Physique — site

Page de vente one-page (HTML/CSS statique) pour Peak Physique.

- Identité : logo sorcier + bleu marine `#134D75` (tokens en haut de `styles.css`)
- Parcours : essai gratuit → Strength Maxxing (39,99 €) → Strength + Speed (49,99 €) → coaching 1:1 (appel gratuit)
- Prix affichés en €, $ ou £ selon le fuseau horaire du visiteur
- Tous les boutons ouvrent WhatsApp avec un message prérempli (programme + prix)

Aperçu local : ouvre `index.html` dans un navigateur.
